# Friend Groups
Friend Groups allows you to create tabs, order them, and just clean up your friends list.

## Settings
### Visual Settings
##### Colour Settings
- Text Colour
- Backdrop Colour

Both the colours only apply to newly made groups or the default 'Ungrouped' group.

##### Text Settings
- Font
- Text Alignment

These settings apply to every tab. This currently can't be set per group.

##### Component Settings
- Draw Backdrop
- Draw Group Box
- Draw Shadows
- Draw Group Count

These settings apply to every tab. This will change how tabs are drawn and some of the titles.

##### Misc
- Recolour Menu Entry
- Name Offset

'Recolour Menu Entry' will recolour the entry inside 'Add to section' to reflect that group's Text Colour.

'Name Offset' insets both the player's name and world widget by however many pixels specified.

### General Settings
'Remove Friend Block' changes the Delete functionality of friends in groups, as 'Remove from section' and 'Delete' sometimes caused accidental deletes.

- Default (Normal Behaviour)
- Recolour (Recolours 'Delete' to Red)
- Consume (Prevent the action)
- Hide (Hide 'Delete' until out of a group)

### Spacing Settings
'Manual Override' allows you to change the default font spacing. This won't make the text bigger, but will allow you to have more control of spacing.

- Font Spacing
- Header Spacing

'Font spacing' changes the backdrop size and the title offset from the friends below.

'Header Spacing' changes the spacing between tabs (backdrops).
